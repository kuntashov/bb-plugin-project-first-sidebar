# Быстрый выбор треда

Откройте палитру команд (`Ctrl+Shift+P`, на macOS `Cmd+Shift+P`) и выберите «Найти тред по фильтру». Для прямого открытия диалога команде можно назначить сочетание в Settings → Keyboard.

Сначала диалог показывает фильтры с иконками и полными названиями. Начните вводить название и нажмите Enter: иконка выбранного фильтра закрепится перед полем, а список сменится на треды его проектов. Первый результат уже выбран; стрелки меняют выбор, Enter открывает тред.

Поиск проверяет все неархивные треды выбранного фильтра независимо от свёрнутых групп и загруженных строк сайдбара. Для вложенного треда используется проект доступной цепочки предков. Закрепление чужого треда не добавляет его в область поиска фильтра.

## Ввод

- `adm:на/сра` — имя проекта содержит `adm`, а название треда содержит `на` и `сра`. Выбранный фильтр продолжает ограничивать проекты.
- `:Исследование:пуб` — поиск `Исследование:пуб` в названии любого проекта выбранного фильтра. Первое `:` отделяет проект, последующие двоеточия буквальны. Пустая сторона не ограничивает соответствующее поле.
- `исс/пуб` — в названии должны встречаться обе части, без учёта регистра.
- `исс/ пуб` — вторая часть включает пробел перед `пуб`.
- `пуб ` — пробел после `пуб` также обязателен.
- `/` разделяет условия. Пустые части игнорируются, часть из пробелов ищется буквально. Порядок частей не задаёт порядок в названии.
- Совпадающие вхождения подсвечиваются фоном. Опечатки не исправляются; `ё` и `е` различаются.

Фильтры, имена проектов и названия тредов ищутся также в другой раскладке: `cthdth` находит `сервер`, а `ыукмук` — `server`. Для каждой части проверяются исходный ввод и его вариант по клавишам стандартных русской и английской раскладок; совпадения обоих вариантов подсвечиваются. Разделители `:` и `/` вводятся буквально, пробелы сохраняются.

Список фильтров использует компактные строки с переносом полного имени. В списке тредов заголовок и проект занимают по одной строке; полный заголовок доступен при наведении.

Поиск идёт по отображаемым названиям, включая разрешённые BB упоминания. Если название упомянутого объекта ещё загружается, текст и результаты обновятся вместе с BB.

## Архив и управление

| Действие | Клавиатура |
| --- | --- |
| Добавить или убрать архив | `Alt+A` либо кнопка «Архив» справа от ввода |
| Выбрать следующую/предыдущую строку | `↓` / `↑` |
| Подтвердить фильтр или открыть тред | `Enter` |
| Вернуться к фильтрам при пустом вводе | `Backspace` |
| Отменить диалог | `Escape` |

При каждом новом открытии архив выключен. Включение добавляет весь архив выбранного набора проектов, сохраняя фразу и фильтр. Архив загружается отдельно; до завершения загрузки диалог сообщает об этом. Выключение исключает архивные результаты сразу, в том числе при незавершённом запросе.

До окончательного Enter сайдбар и открытый тред не меняются. При выборе результата диалог устанавливает выбранный фильтр, открывает тред обычной навигацией BB, раскрывает необходимый путь и фокусирует строку сайдбара. Для архивного результата включается его показ без разархивации. Выбор скрытого результата делает видимым только этот тред; скрытые предки сохраняют статус.

Escape отменяет также подготовку перехода во время закрытия диалога. После начала самого перехода уже применённые изменения не откатываются автоматически; ошибка открытия или позиционирования сообщается явно.
